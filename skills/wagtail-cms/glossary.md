# Wagtail CMS Glossary

**AbstractPage** — Base class for custom page models; provides URL, template, and preview methods without the full Page tree structure (Ch 1)

**AJAX Template** — Alternative template served when a page is requested via XMLHttpRequest, enabling partial page updates (Ch 1)

**BaseLogEntry** — Abstract model recording actions performed on objects in the Wagtail admin (Ch 1)

**Block** — Reusable content unit within a StreamField, each with its own type, value, and optional template (Ch 2)

**Block preview** — Configurable preview shown in the block picker when adding a block in the editor (Ch 2)

**Block type** — The name identifying a block within a StreamField definition, used in templates to match rendering logic (Ch 2)

**CharBlock** — Simple block type for single-line text input within a StreamField (Ch 2)

**Child page** — A page nested under a parent page in the Wagtail page tree hierarchy (Ch 1)

**Classname** — Panel parameter that adds CSS classes to the panel's HTML element for styling or behavior control (Ch 7)

**Collection** — A grouping of images or documents used for organizing media and applying access permissions (Ch 16)

**Comment** — Annotation attached to a page field or StreamField block, enabling collaborative editing discussion (Ch 1)

**content_panels** — List of Panel objects defining the main content fields shown in the page editor (Ch 1, 7)

**Content type** — A Django model representing a specific page structure; each Wagtail page type is a content type (Ch 1)

**Custom page manager** — A Django Manager subclass for Page models, enabling custom QuerySet methods (Ch 1)

**DraftStateMixin** — Abstract model mixin allowing non-page models to have unpublished draft changes (Ch 1)

**FieldPanel** — Panel class for rendering a single model field in the editor with the appropriate widget (Ch 1, 7)

**FieldRowPanel** — Panel that arranges child panels side-by-side in a columnar layout (Ch 7)

**FilterField** — Index field type that enables filtering search results by a specific field value (Ch 1, 5)

**Focal point** — A coordinate set on an image that controls where cropping occurs with the fill resize rule (Ch 3)

**Full URL** — Absolute URL including protocol and domain, generated by get_full_url with WAGTAILADMIN_BASE_URL (Ch 6)

**GroupPagePermission** — Model linking a Django auth Group to specific page permissions in Wagtail (Ch 1)

**ImageBlock** — Block type providing an image chooser interface within a StreamField (Ch 2, 3)

**include_block** — Template tag that renders a StreamField block's HTML, passing context variables correctly (Ch 2)

**InlinePanel** — Panel for editing a cluster of related child objects via a ParentalKey relation (Ch 1, 7)

**ListBlock** — Block type that allows repeating instances of a child block in any quantity (Ch 2)

**Locale** — Model representing a language or region; each translation tree is rooted in a Locale (Ch 1, 4)

**max_num** — Parameter on StreamField or InlinePanel limiting the maximum number of allowed items (Ch 2, 7)

**min_num** — Parameter on StreamField or InlinePanel requiring a minimum number of items (Ch 2, 7)

**MultiFieldPanel** — Panel that groups several child panels under a single collapsible heading (Ch 7)

**Multiple formats** — Picture tag feature rendering AVIF, WebP, and JPEG sources with automatic browser fallback (Ch 3)

**Orderable** — Abstract model providing sort_order for child objects that can be reordered in the admin (Ch 1)

**Page** — Core Wagtail model; all page types inherit from it, forming a tree-based content structure (Ch 1)

**Page description** — Short text displayed when creating or selecting a page type, guiding editors on its purpose (Ch 1)

**Page model** — A Django model inheriting from Page, defining a content type with custom fields and panels (Ch 1)

**Page URL** — The web address for a page, obtained via get_url or the pageurl template tag (Ch 1)

**PageChooserPanel** — Panel for ForeignKey fields pointing to pages, with optional page type filtering (Ch 7)

**PageViewRestriction** — Model controlling access to pages via password, group, or login requirements (Ch 1)

**Parent page** — The page under which a child page is nested in the page tree (Ch 1)

**parent_page_types** — Page attribute restricting which parent page types this page can be created under (Ch 1)

**ParentalKey** — ForeignKey subclass from django-modelcluster enabling inline child objects on pages (Ch 1)

**Per-block template** — Custom HTML template for a specific block type, overriding default rendering (Ch 2)

**picture** — Template tag rendering <picture> element with format sources and responsive srcset (Ch 3)

**promote_panels** — List of Panel objects for metadata fields like SEO title, slug, and search description (Ch 1, 7)

**read_only** — FieldPanel parameter preventing editors from modifying a field's value (Ch 7)

**required_on_save** — FieldPanel parameter enforcing validation on required fields even when saving drafts (Ch 7)

**Resize rule** — Image tag argument specifying how an image should be scaled, cropped, or formatted (Ch 3)

**Revision** — Immutable snapshot of page content saved each time a page is edited (Ch 1)

**RevisionMixin** — Abstract model mixin enabling non-page models to save and manage revisions (Ch 1)

**RichTextBlock** — Block type providing a rich text editor within a StreamField (Ch 2)

**RichTextField** — Django model field providing a WYSIWYG editor for rich text content (Ch 1)

**search_description** — SEO meta description field available on all Page instances (Ch 1)

**search_fields** — Page attribute defining which fields are indexed for search and filtering (Ch 1, 5)

**SearchField** — Index field type enabling full-text search on a model field (Ch 1, 5)

**serve** — Page method handling HTTP requests; returns a Django Response object (Ch 1)

**show_in_menus** — Boolean field controlling whether a page appears in site-wide navigation menus (Ch 1)

**Site** — Model mapping a hostname and port to a root page, enabling multi-site installations (Ch 1)

**site_name** — Human-readable site identifier shown in the Wagtail admin welcome message (Ch 8)

**slug** — URL-safe identifier for a page, forming part of its web address (Ch 1)

**snippet** — A non-page Django model made editable via register_snippet, used for reusable content (Ch 4)

**Specific** — Property converting a generic Page instance to its concrete model subclass (Ch 1)

**StreamBlock** — Block type defining a mix of child blocks that can be arranged in any sequence (Ch 2)

**StreamField** — Model field storing ordered sequences of typed content blocks as JSON (Ch 2)

**StructBlock** — Block type grouping multiple child blocks into a single composite block (Ch 2)

**subpage_types** — Page attribute limiting which child page types can be created under this page (Ch 1)

**Template** — HTML file rendered when a page is visited, automatically selected by app label and model name (Ch 1)

**Task** — A stage in a workflow that must be approved before the workflow can complete (Ch 1)

**WAGTAILADMIN_BASE_URL** — Setting defining the site's base URL for generating absolute admin links (Ch 8)

**WAGTAIL_CONTENT_LANGUAGES** — List of language codes available for content authoring in Wagtail (Ch 8)

**WAGTAILIMAGES_EXTENSIONS** — List of allowed image file extensions validated during upload (Ch 3, 8)

**WAGTAILIMAGES_JPEG_QUALITY** — Setting controlling global JPEG encoding quality (default 76) (Ch 3, 8)

**WAGTAIL_WORKFLOW_ENABLED** — Setting toggling moderation workflow functionality site-wide (Ch 8)

**Workflow** — A sequence of approval tasks that must complete before content is published (Ch 1)

**WorkflowState** — Tracks the current status of a workflow on a page or snippet instance (Ch 1)

**WorkflowTask** — Through-model linking a Task to a specific Workflow with sort ordering (Ch 1)
