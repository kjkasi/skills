# Glossary

**AfterValidator** — validator that runs after Pydantic's internal type validation; most type-safe (Ch 4)
**AliasChoices** — try multiple alias paths in order until one succeeds (Ch 9)
**AliasPath** — traverse nested dict structures to find a field value (Ch 9)
**BaseModel** — core class for defining validated data schemas (Ch 1)
**BeforeValidator** — validator that runs before Pydantic's type validation; handles raw input (Ch 4)
**ComputedField** — derived field calculated from other fields (Ch 2)
**ConfigDict** — typed configuration dictionary for model behavior (Ch 7)
**Core Schema** — internal compiled validation logic representation (Ch 17)
**create_model** — dynamically create model classes at runtime (Ch 20)
**Discriminator** — callable or string that selects which union member to validate (Ch 8)
**ExtraValues** — configuration for handling extra fields: 'ignore', 'forbid', 'allow' (Ch 7)
**Field** — function to customize field defaults, constraints, aliases, and metadata (Ch 2)
**FieldInfo** — internal representation of a field's configuration (Ch 2)
**field_validator** — decorator for custom field-level validation logic (Ch 4)
**field_serializer** — decorator for custom field-level serialization logic (Ch 5)
**from_attributes** — config flag to validate from arbitrary objects/ORM instances (Ch 7)
**model_config** — class attribute holding ConfigDict for a model (Ch 7)
**model_construct** — create model instances without validation (use with trusted data only) (Ch 1)
**model_dump** — serialize model to Python dictionary (Ch 5)
**model_dump_json** — serialize model directly to JSON string (Ch 5)
**model_fields** — class attribute mapping field names to FieldInfo (Ch 2)
**model_fields_set** — set of fields explicitly provided during instantiation (Ch 1)
**model_json_schema** — generate JSON Schema dictionary from model (Ch 6)
**model_rebuild** — rebuild model schema for forward references or generics (Ch 1)
**model_validate** — validate dictionary or model instance against model (Ch 1)
**model_validate_json** — validate JSON string against model (Ch 1)
**model_validate_strings** — validate dictionary with string values using JSON-mode rules (Ch 1)
**model_validator** — decorator for custom whole-model validation (Ch 4)
**model_serializer** — decorator for custom whole-model serialization (Ch 5)
**PlainSerializer** — serializer that unconditionally replaces default serialization (Ch 5)
**PlainValidator** — validator that terminates validation immediately after returning (Ch 4)
**PydanticCustomError** — raise validation errors with custom types and messages (Ch 15)
**PydanticUserError** — configuration or programming error (not validation error) (Ch 15)
**RootModel** — model that wraps a single root value instead of named fields (Ch 1)
**SchemaSerializer** — Rust-based serialization engine in pydantic-core (Ch 17)
**SchemaValidator** — Rust-based validation engine in pydantic-core (Ch 17)
**SecretStr** — string type that hides value in repr/logs (Ch 3)
**SecretBytes** — bytes type that hides value in repr/logs (Ch 3)
**strict mode** — validation mode requiring exact type matches without coercion (Ch 10)
**StrictInt / StrictFloat / StrictStr / StrictBool** — types that reject coercion in any mode (Ch 10)
**Tag** — assigns discriminator values to union members (Ch 8)
**TypeAdapter** — standalone validation for any type without defining a model (Ch 13)
**TypeAliasType** — named type alias using PEP 695 syntax (Ch 3)
**TypedDict** — dictionary type with fixed keys and typed values (Ch 3)
**TypeVar** — generic type variable for parameterized types (Ch 3)
**Union** — type accepting one of multiple member types (Ch 8)
**ValidationError** — exception raised when validation fails (Ch 15)
**validate_call** — decorator validating function arguments against type hints (Ch 14)
**validate_default** — config/field flag to validate default values (Ch 2)
**validate_by_name** — config flag allowing both field name and alias during validation (Ch 7)
**WrapSerializer** — serializer that wraps the default serialization logic (Ch 5)
**WrapValidator** — validator that wraps the entire validation pipeline (Ch 4)
**WithJsonSchema** — attach custom JSON schema metadata to a type (Ch 6)
